# PHP Book Library

A university assignment project built with PHP and Bootstrap 5 for managing a personal book library.  
The application allows users to add and view books with form validation, sessions, and dynamic table display.

## Features
- Add new books
- Form validation
- Bootstrap 5 responsive design
- Success and error messages
- Session handling
- Dynamic book table

## Technologies Used
- PHP
- Bootstrap 5
- HTML
- Sessions & Arrays
